# Input, Output and Strings

Think about any program you've ever used — it takes something in, and it gives something back. That's input and output. Today, you're going to learn how to make it happen in your own code.

## Output

Let's start with the simplest thing: getting your program to show something on the screen. In Python, you use the `print()` function:

```python
print("Hello, world!")
```

Whatever you put inside the parentheses gets displayed. You can print text, numbers, or both:

```python
print("My age is")
print(25)
```

Each `print()` starts a new line, so the output above looks like this:

```
My age is
25
```

## Strings

A string is simply a piece of text — anything from a single letter to a whole sentence. In Python, strings are written inside quotes:

```python
name = "Alice"
greeting = 'Hello, world!'
```

You can use either single quotes (`'`) or double quotes (`"`), as long as they match.

### Joining Strings Together

You can combine strings using the `+` operator. This is called **concatenation**:

```python
first = "Hello"
second = "world"
message = first + " " + second
print(message)   # prints Hello world
```

Notice the `" "` in the middle — that's a string containing a single space, added so the two words don't run together.

Without that space, you'd get `Helloworld`, which probably isn't what you want:

```python
print("Hello" + "world")   # prints Helloworld
```

You can join as many strings as you like:

```python
print("My" + " " + "name" + " " + "is" + " " + "Alice")
# prints My name is Alice
```

### Strings and Variables Together

Often you'll want to mix text with a variable's value. One easy way is the **f-string** (formatted string). Just put an `f` before the quotes, and wrap variables in curly braces `{}`:

```python
name = "Alice"
print(f"Hello, {name}!")
# prints Hello, Alice!
```

The `{name}` gets replaced by whatever is stored in the variable `name`. You can put more than one variable in the same string:

```python
first = "Alice"
last = "Smith"
print(f"Hello, {first} {last}!")
# prints Hello, Alice Smith!
```

## Input

So far, your programs have only produced output. But real programs also need to *receive* information from the user. That's what the `input()` function does.

```python
place = input("Where do you live?")
print(f"You live in {place}")
```

When Python reaches `input()`, it pauses and waits for the user to type something and press Enter. Whatever the user types is stored in the variable `place`.

The text inside the parentheses, `"Where do you live?"`, is called a **prompt**. It's shown to the user so they know what to type. Notice the space at the end — it keeps the user's typing from running into the question mark.

**Sample run:**

```
Where do you live? New York
You live in New York
```

The text the user typed "`New York`" is what got stored in `place`, and it's what appears in the final message.

## Summary

In this lesson, you learned:

- **`print()`** displays output on the screen.
- **Strings** are pieces of text, written inside quotes.
- **Concatenation** joins strings together with the `+` operator.
- **f-strings** let you insert variables directly into text using `{}`.
- **`input()`** reads text typed by the user and stores it in a variable.

You now have the two essential pieces of any program: **input** and **output**. In the next lesson, we'll build on these to make your programs smarter and more interactive.
